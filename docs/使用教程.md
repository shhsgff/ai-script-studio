## 1. 第一次打开

如果你手上是 `AI Script Studio-1.1.3-portable.exe`：

1. 双击运行。免安装版每次启动会先解压到临时目录，**首次大约要 3~8 秒**，之后再开就快；
2. Windows 可能弹「已保护你的电脑」（因为 exe 没有做代码签名）→ 点 **更多信息 → 仍要运行**；
3. 看到**欢迎页**就对了：

```
                    🪶
            AI 智能剧本创作工具
   还没有打开的剧本。新建一个，或者从本地导入已有文稿。

 ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
 │    ＋    │ │    🤖    │ │    📂    │ │    📄    │
 │ 新建剧本 │ │用关键词生成│ │ 打开项目 │ │ 导入文稿 │
 └──────────┘ └──────────┘ └──────────┘ └──────────┘

       Ctrl+N 新建 · Ctrl+O 打开 · Ctrl+Shift+G DSH 生成
```

四个入口：

| 入口 | 作用 |
| --- | --- |
| **新建剧本** | 建一个**空白**剧本：只有 1 章「第一章：未命名章节」、0 小节、0 字 |
| **用关键词生成** | 调本机 DeepSeek Harness，按关键词自动分章分节写一本（见第 6 节） |
| **打开项目** | 打开之前存的 `.aisc` 文件（会作为新标签打开，不覆盖当前工作） |
| **导入文稿** | 导入 `.txt` / `.md` / `.html`，自动识别章节（见第 9 节） |

底部还会列出**最近打开**的文件，点一下直接打开。

> 状态栏右下角那行是提示行，会告诉你「从新建剧本开始吧」「已回到上次的工作现场（2 个剧本）」这类信息。
> 左下角 `○ AI 未配置` 表示 AI 配置没就绪；正常应该是 `● dsh-local · 本地`。

## 2. 新建、打开、标签栏

菜单栏下面那条就是**标签栏**，像浏览器一样：

```
[ 长安夜行录 ● ✕ ] [ 废土拾荒者 ✕ ]  ＋                    🤖 DSH 生成  🗺️
```

- 标签名后面的 **●** = 有未保存修改；
- **✕** 关闭这个标签（鼠标移上去才显示；有未保存会问你「保存 / 不保存 / 取消」）；
- 最左边 **＋** = 新建空白剧本；
- 双击标签名 = 就地改名（回车确认，Esc 取消）；
- 中键点标签 = 关闭；
- **右键标签**打开菜单：

| 右键项 | 作用 |
| --- | --- |
| 重命名 | 同双击 |
| 保存 / 另存为 | 存盘（首次保存会让你选路径） |
| 关闭标签 | 关这一个 |
| 关闭其他标签 | 只留这一个（其余有修改会逐个询问） |
| 关闭全部标签 | 回到欢迎页 |
| 在文件夹中显示 | 用资源管理器定位这个 `.aisc` 文件 |

> 关掉最后一个标签就回到欢迎页，状态栏的字数、标题都会清零，不会残留上一次的数字。

## 3. 左边：章 → 节两级目录

```
剧本目录                          ＋   ← 加一章
┌────────────────────────────────────┐
│ ▾ 1  第一章：雨            60  ↑↓＋✕ │
│      ● 刀在雨里            48  ↑↓✕  │
│      ● 鞘上三字            71  ↑↓✕  │
│ ▸ 2  第二章：灯            25        │
└────────────────────────────────────┘
```

- **点章名** → 切到这一章（中间编辑器换成这一章，标题就是章名）；
- **双击章名** → 就地改名；
- 章行右边的按钮：**↑ ↓** 调整章节顺序、**＋** 在这一章末尾**加一个小节**、**✕** 删除这一章；
- 章名左边的小三角 = **折叠/展开**这一章的小节；
- **点小节名** → 滚动定位到正文里那一段，并把光标放进去；
- 小节行右边的 **↑ ↓ ✕** = 小节排序 / 删除；双击小节名改名；
- 小节的圆点 + 数字 = 这一小节当前字数（0 字显示为灰色圆点）。

> 章 = 一个编辑页；小节 = 正文里的 `<h2 data-section="…">标题</h2>` 锚点。
> 这么设计的好处：`.aisc` 文件仍然是纯 HTML 结构，用任何工具都能读，也方便导入导出。

## 4. 中间：编辑区

- 正文区域**直接打字**，所见即所得；
- 右侧有**常驻细滚动条**，滚轮、PageUp/PageDown、拖条都能翻；纸张会随内容变长，不会把字挤到纸外面；
- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`（每章独立 150 步，切换标签不会丢）；
- **选中文字**后会浮出小工具条：润色 / 扩写 / 缩写 / AI 改写…（点「AI 改写…」会直接带着选中文本跳到右侧面板）；
- **查找替换**：`Ctrl+F` 打开底部查找栏（输入即高亮全部命中，`Enter` 下一个、`Shift+Enter` 上一个）；`Ctrl+H` 直接展开替换框，可以「替换当前」或「全部替换」；
- 右上角小胶囊显示「全篇 N 字 · 本章 M 字」（设置里可以关掉）；
- 状态栏实时显示：全篇字数、字符数、本章字数、保存状态、AI 状态。

### 编辑菜单里还有什么

| 菜单项 | 作用 |
| --- | --- |
| 撤销 / 重做 | 同快捷键 |
| 查找 / 替换 | 打开查找栏 |
| 字数统计 | 弹窗列出**每一章**的字数、字符数、小节数，以及全篇合计 |
| 全选本章 | 选中当前章全部正文 |
| 复制全章 | 把当前章纯文本复制到剪贴板 |
| 清除格式 | 把选中内容替换成纯文本（去掉粘贴进来的粗体、颜色、链接等） |

## 5. 右边：AI 智能辅助

从上到下依次是：

1. **参考图 / 场景图**：点虚线框上传一张图（存到用户目录）。只有你在设置里勾了「当前模型支持图片输入（视觉模型）」，图片才会随请求发给模型；
2. **当前选中文本**：自动显示你选了哪一段（多少字 / 多少字符）。没选也能用（会按下面的「上下文」处理）；
3. **改写要求（提示词）**：写你想要的效果，比如「改成古龙式短句，留白、带悬念」；
4. **基础操作**：润色 / 扩写 / 缩写 —— 点一下就把对应提示词填好；
5. **常用指令**：画面感 / 神态心理 / 口语化 / 提速 / 校对 —— 同样是一句话模板；
6. **模型**：默认 `dsh-local（本机网关）`；想用外部服务商就在下拉里换成 `deepseek-chat` / `deepseek-reasoner`，或在设置里填自定义模型名；
7. **上下文**：
   - `仅选中段落` —— 只把选中的那段发给模型；
   - `整章作为参考` —— 附上整章正文，让模型保持上下文一致；
   - `前文 + 选中段落` —— 附上这一章里选中处之前的内容；
8. **🚀 立即调用 AI 改写**（`Ctrl+Enter`）：开始流式生成，正文按字往外吐；
9. **结果面板**：状态（生成中… / 已完成 · N 字）、**采纳**（`Ctrl+Shift+Enter`，替换掉选中的那段并标记为未保存）、**重试**、**复制**、**放弃**、**停止**（生成中可用）；
10. **改写记录**：每次改写的模型、时间、结果摘要都留着，方便回看；「清空」清掉记录（不影响正文）。

> **不用买 Key**：软件启动时会在本机 `127.0.0.1:45872` 起一个 OpenAI 兼容网关，
> 用一枚自动生成的本地密钥 `aisc-local-…` 转发给你已登录的 `dsh`。
> 想复制 / 重新生成这枚密钥，或者临时关掉网关：**设置 → AI 配置 → 本地网关**。

## 6. 用 DSH 关键词生成剧本

点右上角 **🤖 DSH 生成**（或 `Ctrl+Shift+G`）：

| 项 | 说明 |
| --- | --- |
| 关键词 / 设定 | 一句话到一段话都行，比如「一个失忆的刀客在长安城里找寻自己的名字，中途卷入一场宫廷密谋」 |
| 章节数 | 想要几章（默认 3，可在设置里改上限） |
| 每章字数 | 大约多少字（默认 800） |
| 文风 | 「古龙式短句、留白、悬念」这类描述 |
| 自动划分小节 | 勾上就要求模型按 2~4 小节组织每章 |

点 **开始生成** 后会：

1. 调本机 `dsh headless --json`（也就是你终端里那个 `dsh`），日志区逐行显示进度（已连接 → 思考中 → 正在整理输出）；
2. 收到 JSON 后自动解析、分章分节；
3. **新开一个标签**放进去，标签名 = 生成的剧本标题，并直接定位到第一章。

生成中可以点「停止」。整个任务跑在系统临时目录里，并明确要求模型「只输出 JSON、不要写文件、不要调用工具」。

> 找不到 dsh？设置 → DSH / MCP 里会显示「✓ 已找到 dsh（版本）」或「✗ 未找到」，
> 可以在「dsh 命令」里填绝对路径，例如 `C:\\Users\\<你>\\AppData\\Roaming\\npm\\dsh.cmd`。

## 7. 让 DSH 反向写进本软件（MCP）

两个方向都支持：

- **正向**（第 6 节）：本软件 → 调 dsh，一次生成；
- **反向**（本节）：DSH 的 agent → 调本软件，边聊边写。

### 7.1 开服务

设置 → **DSH / MCP** → MCP 接口 → 点 **开启 MCP 服务**。
它会在本机 `127.0.0.1:45871` 起一个 HTTP 桥（只认带 token 的请求），并在用户目录生成两个文件：

```
%APPDATA%\ai-script-studio\mcp\mcp-server.js     ← stdio MCP server（给 DSH 拉起来）
%APPDATA%\ai-script-studio\mcp\mcp-bridge.json  ← 端口 + 密钥
```

### 7.2 一键注册到 DSH

同一个面板往下 → **自动注册到 DeepSeek Harness**：

1. 选「注册到哪个 profile」（下拉里列出你本机所有 dsh profile，比如 `headless` / `web`）；
2. 点 **一键注册到 DSH**。

它做的事：

- 找到 `DSH_HOME`（默认 `~\\.dsh`）与 `profiles/<profile>/cordis.patch.yml`；
- 用 `dsh --dump-config` **反查你这个版本真正使用的 MCP 客户端插件名**（换版本也不用改）；
- 写入前先备份成 `cordis.patch.yml.bak-<时间戳>`；
- 写入是**幂等**的：重复点不会写重复条目；
- 写完立刻用 `dsh --dump-config` 回读校验，面板给出 ✓ 或 ⚠。

> 想撤销：点 **撤销注册**，文件会还原成注册前的样子（只把本软件加的那一段删掉）。
> 想手动配别的工具（Claude / Cherry Studio 之类）：点「复制配置片段」拿到 YAML，或参考面板里的 JSON 版本。

### 7.3 在 DSH 里怎么用

注册完，在 dsh 里对话时它就能看到 `ai-script-studio` 这组工具：

| 工具 | 参数 | 作用 |
| --- | --- | --- |
| `create_script` | `title`、`chapters[{title, paragraphs[] 或 sections[{title, paragraphs[]}]}]` | 新建一整本剧本（作为新标签打开） |
| `add_chapter` | `title`、`paragraphs[]` 或 `content` | 往当前剧本追加一章 |
| `append_text` | `chapter`（章名，可省略 = 当前章）、`text` | 往指定章追加正文 |
| `list_scripts` | — | 列出当前打开的剧本（标题、路径、章数、字数、是否活动） |
| `get_script` | `title`（可省略 = 当前标签）、`maxChars` | 读回正文，便于它接着改 |

举个例子，在 dsh 里说：

> 用 ai-script-studio 帮我建一本《雨夜刀》，两章，每章两节，古龙风格。

它就会调 `create_script`，本软件里立刻多出一个标签。

## 8. 保存、备份、自动存档、工作现场

### 保存

- `Ctrl+S` 保存；`Ctrl+Shift+S` 另存为；第一次保存会弹系统对话框，默认存到「文档」目录；
- 文件后缀 `.aisc`，本质是 **JSON**（见第 12 节），可以直接用文本编辑器看；
- 保存后标签上的 ● 消失，状态栏变 `● 已保存`。

### 备份

每保存一次，软件会在 `%APPDATA%\ai-script-studio\backups\` 留一份历史副本（最多保留最近 20 份）。误删内容又保存了？去这里翻上一版。

### 自动存档（防崩溃）

每 15 秒把**脏文档**写进 `autosave.json`。下次启动会提示「已恢复上次的自动存档草稿」。**纯空白草稿不会被恢复**（只建了个空剧本就关掉的，不会留下垃圾）。

### 工作现场（下次打开还是一样）

软件会记住「当前开着哪些已保存的剧本、哪个是活动标签」（`session.json`），下次启动自动重新打开，右下角提示「已回到上次的工作现场（N 个剧本）」。把标签全关掉再退出，就不记了 —— 下次回到欢迎页。

## 9. 导入与导出

### 导入（文件 → 导入文稿，`Ctrl+I`）

支持 `.txt` / `.md` / `.html`，规则：

| 类型 | 怎么分章 |
| --- | --- |
| Markdown | 按 `#` / `##` / `###` 标题分章，标题文字就是章名 |
| HTML | 按 `h1`–`h6` 分章，脚本、样式、导航、页脚会被丢掉 |
| 纯文本 | 按「第X章 / 第X幕 / 第X节 / 序章 / 楔子 / 尾声 / 番外」这类行首标题分章 |
| 都不匹配 | 整篇作为一章「正文」 |

导入会**新建一个标签**，不会覆盖你当前正在写的。

### 导出（`Ctrl+Alt+W` / `P` / `T`，或文件菜单）

| 格式 | 说明 |
| --- | --- |
| Word（.docx） | 标题 + 每章 + 每节，正文宋体小四、1.5 倍行距、首行缩进 |
| PDF | 用 Chromium 打印成 PDF，A4、页边距 20mm（没有页码和页眉） |
| 纯文本（.txt） | 章名 + 正文，UTF-8 |

导出完会自动在资源管理器里定位到那个文件。

## 10. 外观：主题、壁纸、字体、大纲浮窗

设置面板（`设置` 菜单 / 右上角按钮）有五个页签：

| 页签 | 能改什么 |
| --- | --- |
| 壁纸 | 上传图片或视频做背景；**压暗**（0~100%）、**模糊**（0~20px）；恢复默认 / 换成纯色 |
| 字体排版 | 正文字体、字号、行距、段间距、首行缩进、是否显示字数标尺（右上角小胶囊） |
| AI 配置 | 本地网关（地址 / 密钥 / 重新生成 / 测试）+ 服务接口（Base URL / API Key / 模型 / 创造性 / 最大 tokens / 系统提示词 / 视觉开关）+ 测试连接 |
| DSH / MCP | 检测 dsh、dsh 命令路径、每次生成最多章节、MCP 服务开关、一键注册到 DSH、复制配置片段 |
| 关于 | 版本号、数据目录真实路径 |

- **快捷换主题**：右上角 🌙 / ☀️，或 `Ctrl+Shift+L`；
- **故事大纲浮窗**（`Ctrl+Shift+O`，或右上角 🗺️）：列出全篇章 / 节与字数，**光标在哪个小节，哪一行就高亮**；写过的是亮色，没写过的是灰色；点条目直接跳转；标题栏可以拖动，位置会记住。

## 12. 数据都存在哪

| 内容 | 路径 |
| --- | --- |
| 设置、最近文件、主题、排版 | `%APPDATA%\ai-script-studio\settings.json` |
| 自动存档（未保存草稿） | `%APPDATA%\ai-script-studio\autosave.json` |
| 工作现场（下次打开哪些文件） | `%APPDATA%\ai-script-studio\session.json` |
| 本地网关地址与密钥 | `%APPDATA%\ai-script-studio\gateway.json` |
| MCP 服务端脚本与桥配置 | `%APPDATA%\ai-script-studio\mcp\` |
| 每次保存的历史备份 | `%APPDATA%\ai-script-studio\backups\` |
| 上传的壁纸 / 参考图 | `%APPDATA%\ai-script-studio\wallpapers\` |

设置 → 关于 里会直接显示当前机器上的**真实路径**。

### `.aisc` 文件长什么样

```json
{
  "version": 1,
```

## 13. 常见问题

**Q：双击 exe 没反应 / 很久才出窗口？**
免安装版每次启动要先解压（3~8 秒）。装安装版（`-x64.exe`）会快很多。

**Q：状态栏显示「○ AI 未配置」，点 AI 改写报错？**
说明本地网关没起来或密钥被清空了。设置 → AI 配置 → 本地网关，看是不是「✓ 网关运行中」；不在就点「开启网关」，再点「填入下面的 AI 配置」。

**Q：`dsh` 找不到？**
设置 → DSH / MCP 会显示检测结果。终端里 `dsh --version` 能出版本才行；不行就把「dsh 命令」改成绝对路径，例如 `C:\\Users\\<你>\\AppData\\Roaming\\npm\\dsh.cmd`。

**Q：网关跑在别的端口？**
默认 `127.0.0.1:45872`，被占用会自动顺延。真实地址看设置面板上的「网关运行中 · 地址」，或 `gateway.json`。

**Q：一键注册到 DSH 报 ⚠？**
先看面板里的路径对不对（`DSH_HOME` 和 profile）。可以点「重新扫描」刷新 profile 列表；个别 dsh 版本需要用别的 MCP 客户端插件名，软件会自动探测，探测不到就用默认值并提示你。

**Q：误删了一章能找回吗？**
可以：`backups\` 里有每次保存的历史副本（最近 20 份）。

**Q：能同时在两台电脑用吗？**
数据在本机用户目录，不同步。把 `.aisc` 文件拷过去打开即可。

**Q：支持 macOS / Linux 吗？**
源码是跨平台的（Electron），但打包脚本目前只配了 Windows target。
