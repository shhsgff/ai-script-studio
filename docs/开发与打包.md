## 1. 技术栈

| 项 | 版本 / 选择 |
| --- | --- |
| 运行时 | Electron 44.9.0（Chromium + Node，Windows x64） |

## 2. 代码结构

```

  dsh.js            本机 dsh 调用：detect / run（流式 NDJSON）/ makeBridge
  dsh-mcp.js        把本软件注册进 DSH：找 DSH_HOME、写 cordis.patch.yml、校验、撤销

  mcp-server.js     stdio MCP server（给 DSH 拉起来，转发到 HTTP 桥）
  mock-ai.js        测试用本地 SSE 假服务（不打进安装包）
  smoke.js          冒烟测试驱动（主进程侧）
  smoke-renderer.js 冒烟测试场景（渲染层侧，在页面里跑）
src/
  index.html        唯一页面（含全部弹窗与面板）
  styles.css        全部样式（暗/亮主题靠 :root 变量切换）
  js/
    utils.js        U：$ / el / debounce / 字数统计 / toast / confirmBox
    store.js        Store：设置读写与应用（主题、字体、壁纸）
    project.js      Project：单份剧本的数据模型 + 小节切分/增删改排序
    workspace.js    Workspace：多文档（标签）管理
    editor.js       Editor：contenteditable、撤销栈、选区、光标所在小节
    outline.js      Outline：左侧目录（章 → 节两级）
    outlinefloat.js OutlineFloat：故事大纲浮窗
    tabs.js         Tabs：标签栏渲染与右键菜单
    ai.js           AIPanel：AI 改写面板（流式、结果、采纳）
    find.js         Find：查找替换

## 3. 进程模型与安全

```
主进程 (main.js)
  ├─ BrowserWindow ── preload.js ── contextBridge ── window.api.*
  │                    页面 (src/index.html + 12 个 js)
  ├─ http server（MCP 桥 127.0.0.1:45871，可选）
  ├─ http server（本地 AI 网关 127.0.0.1:45872，默认开）
  └─ 子进程：dsh headless --json -
```

窗口安全设置：

```js
webPreferences: {
  preload: path.join(__dirname, "preload.js"),
  contextIsolation: true,     // 页面拿不到 Node
  nodeIntegration: false,
  sandbox: false              // preload 需要 require("electron")
}
```

页面 CSP（`index.html` 的 `<meta>`）：

```
default-src 'self';
img-src / media-src 'self' appmedia: data: blob:;
style-src 'self' 'unsafe-inline';
script-src 'self';
connect-src 'self'
```

注意两点：

1. `connect-src 'self'` 意味着渲染进程**不能**随便 fetch 本地端口 —— 所有外部请求（AI、DSH、MCP 桥）都必须走主进程。
2. 壁纸和参考图用自定义协议 `appmedia://` 读取（支持 Range，所以视频能拖进度）：

```js
protocol.registerSchemesAsPrivileged([{ scheme: "appmedia", privileges: { standard: true, secure: true, supportFetchAPI: true, stream: true, bypassCSP: true } }]);
// appmedia://local/?p=<URL 编码后的绝对路径>，只允许 USER_DIR 下的文件
```

窗口其它约定：无系统菜单（`Menu.setApplicationMenu(null)`）、单实例锁、`window.open` 一律交给系统浏览器、窗口位置尺寸记忆、关闭前拦截未保存（`app:dirty` + 三按钮对话框）。

## 4. IPC 一览

| 域 | 通道 | 说明 |
| --- | --- | --- |

| project | `project:open` / `project:openPath` / `project:save` / `project:saveAs` / `project:importText` / `project:backup` | 文件对话框与读写 |
| autosave | `autosave:write` / `autosave:read` / `autosave:clear` | 崩溃恢复草稿 |
| session | `session:write` / `session:read` / `session:clear` | 工作现场（下次打开哪些文件） |
| recent | `recent:remove` / `recent:clear` / 事件 `recent:changed` | 最近文件 |
| wallpaper | `wallpaper:pick` / `wallpaper:clear` | 壁纸文件拷贝进 USER_DIR |
| export | `export:txt` / `export:docx` / `export:pdf` | 三种导出 |
| ai | `ai:start` / `ai:abort` / `ai:test` / 事件 `ai:event` | OpenAI 兼容请求（流式） |
| dsh | `dsh:detect` / `dsh:test` / `dsh:start` / `dsh:abort` / 事件 `dsh:event` | 调本机 dsh |

| mcp(dsh) | `mcp:dshStatus` / `mcp:dshInstall` / `mcp:dshUninstall` | 注册进 DSH 的 cordis.patch.yml |
| gateway | `gateway:status` / `gateway:enable` / `gateway:disable` / `gateway:rotate` / `gateway:apply` / `gateway:test` | 本地网关 |
| 其它 | `clipboard:write` / `clipboard:read` / `shell:showItem` / `shell:openPath` / `shell:openExternal` | 系统能力 |

## 5. 数据文件

全部在 `app.getPath("userData")`（Windows 上是 `%APPDATA%\ai-script-studio\`）：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 主题、字体排版、壁纸、AI 配置、DSH/MCP/网关配置、最近文件 |
| `autosave.json` | 每 15 秒写入的脏文档草稿 |
| `session.json` | 工作现场：`{ files: [...], active: "..." }` |
| `gateway.json` | 网关实际地址与端口（运行中时写） |
| `mcp-meta.json` | MCP 桥是否开启、端口、token |
| `mcp/mcp-server.js` | 从 `electron/mcp-server.js` 复制出来的一份（给 DSH 用） |
| `mcp/mcp-bridge.json` | `{ port, token, pid, updatedAt }` |
| `backups/` | 每次保存的历史副本（最多 20 份） |
| `wallpapers/` | 上传的壁纸文件 |

写文件的规矩：`writeJSONAtomic`（先写 `.tmp-<随机>` 再 `rename`），避免断电写坏；读用 `readJSONSync(file, fallback)`，坏文件退化成默认值而不是崩溃。

## 6. AI 改写链路：本地网关

「AI 改写」不直接对外发请求，而是打到**本机网关**。

```
页面 AIPanel.run()
  └─ api.aiStart({ messages, baseUrl: 127.0.0.1:45872/v1, apiKey: aisc-local-xxx })
      └─ 主进程 runAI()：net.fetch(url + "/chat/completions")，SSE 逐行解析 "data:"
          └─ 本地网关 local-gateway.js
              └─ buildTask(messages) 拼成中文任务
                  └─ spawn: dsh headless --json -
                      └─ 逐行 NDJSON → 转成 OpenAI 的 chunk 推回页面
```

网关要点（`electron/local-gateway.js`）：

- 只 `listen(127.0.0.1)`，外部网络访问不到；
- 校验 `Authorization: Bearer <本地密钥>`（也接受 `x-api-key`），密钥是 `aisc-local-` + 40 位 hex，首次启动自动生成并写进 `settings.api`；
- 路由：`POST /v1/chat/completions`（`stream:true` 走 SSE，`false` 返回整包）、`GET /v1/models`、`GET /health`；
- 端口被占用自动顺延（默认 45872），真实地址看 `gateway.json` 或设置面板；
- `buildTask` 会告诉模型「只输出改写后的正文、不要解释」，并带上上下文/风格约束；
- 想换成真 DeepSeek 官方接口：设置里把 Base URL 改回 `https://api.deepseek.com/v1` 并填自己的 Key 即可，主进程的 `normalizeChatUrl` 会自动补 `/chat/completions`。

主进程请求侧的保护：

- 90 秒没有新数据 → `AbortController.abort()`，提示「长时间没有收到数据…」；
- 401/402/403/404/429/5xx 统一翻译成中文提示（`friendlyAiError`）；
- `ai:test` 有 20 秒硬超时。

## 7. DSH 关键词生成链路

```
DshGen.run()
  └─ api.dshStart({ task, command, timeoutMs })
      └─ dsh.js run(): spawn(command, ["headless","--json","-"], { shell: true, cwd: os.tmpdir() })
          └─ child.stdin.write(task) 然后 end()      // 任务走 stdin，避免引号地狱
              └─ stdout 逐行 JSON.parse：
                   {type:"session"} {type:"status",phase:"turn_start"} {type:"thinking"}
                   {type:"text",text}  {type:"status",phase:"step_end",usage}
                   {type:"status",phase:"turn_end"} {type:"final",text}
```

- 事件经 `webContents.send("dsh:event")` 推给页面，日志区逐行显示；
- 硬超时（默认 240 秒，设置里可改）到点用 `taskkill /pid <pid> /T /F` 杀进程树；
- `cwd` 指到系统临时目录，并在任务里明确「不要写文件、不要调用工具、只输出 JSON」；
- 页面侧 `DshGen.extractJson()` 先剥 ```` ``` ```` 围栏，再取第一个 `{` 到最后一个 `}`，尾逗号容错；解析失败退化成「按段落自动分章分节」，不会白跑一趟。

## 8. MCP 反向写入链路

三段组成：

```
DSH agent
  └─ stdio: node mcp-server.js mcp-bridge.json     （DSH 按配置拉起）
      └─ HTTP POST 127.0.0.1:45871/rpc  + x-aisc-token
          └─ 主进程 mcp 桥（dsh.js makeBridge）
              └─ webContents.send("mcp:request", { id, action, args })
                  └─ 页面 App.mcpHandle(action, args)：直接改 Project / Workspace
                      └─ api.mcpReply(id, { ok, value })  ← 20 秒超时
```

### 8.1 桥（主进程）

- 默认端口 45871，只 `127.0.0.1`，每个请求校验 `x-aisc-token`；
- 只接受 `POST /rpc`，body 上限 8MB；
- 没开时 `mcp-bridge.json` 里的端口/token 仍保留，DSH 拉起 server 会拿到「未开启」的明确错误而不是超时。

### 8.2 stdio server（`electron/mcp-server.js`）

- 行分隔 JSON-RPC，stdout 只写协议，日志一律走 stderr；
- 实现 `initialize`（回显客户端 `protocolVersion`）、`notifications/initialized`、`ping`、`tools/list`、`tools/call`、`resources/list`、`prompts/list`，并吞掉 `notifications/cancelled` 等；
- 五个工具：`create_script` / `add_chapter` / `append_text` / `list_scripts` / `get_script`；
- 转发失败返回 `{ content:[{type:"text",text:"错误：…"}], isError:true }`，不让 DSH 卡住。

### 8.3 注册进 DSH（`electron/dsh-mcp.js`）

DSH **不读** Claude 风格的 `mcpServers` JSON，它的真源是 profile 层的 loader patch：

```
$DSH_HOME/profiles/<profile>/cordis.patch.yml
```

（`DSH_HOME` 默认 `~\.dsh`）。所以注册流程是：

1. `dshHome()` 找 DSH_HOME，扫 `profiles/*` 列出可选 profile；
2. `detectPluginName(profile)` 跑 `dsh --profile <p> --dump-config`，用正则找出**这个版本**真正的 MCP 客户端插件名（默认 `@deepseek-ai/dsh-mcp-client`），版本换了也能对上；
3. `buildBlock()` 生成带固定标记的一段 YAML：

```yaml
# >>> ai-script-studio MCP (auto-added by AI Script Studio) >>>
- insert:
  - id: mcp-ai-script-studio
    name: "@deepseek-ai/dsh-mcp-client"
    config:
      serverName: ai-script-studio
      transport: stdio
      command: node
      args:
        - "<userData>\\mcp\\mcp-server.js"
        - "<userData>\\mcp\\mcp-bridge.json"
      toolCallTimeoutMs: 120000
# <<< ai-script-studio MCP <<<
```

4. `install()` 先备份成 `cordis.patch.yml.bak-<时间戳>`，再写入；文件原本只有注释和 `[]` 时直接替换，否则追加；**幂等**（重复点不会写两遍）；
5. `verify()` 再跑一次 `dsh --dump-config` 回读，确认条目在；
6. `uninstall()` 把标记块剥掉，回到「注释头 + `[]`」。

### 8.4 忙状态：机器写 vs 人写

`src/js/utils.js` 里有个极小的 `window.Busy` 登记表：

| API | 作用 |
| --- | --- |
| `Busy.begin(key,label)` / `Busy.end(key)` | 登记 / 注销一个长任务（目前只有 `dsh`） |
| `Busy.blocker(key)` | 除自己以外还有谁在跑 → 用来拦 AI 改写 |
| `Busy.onChange(cb)` | 状态变化回调：`body.app-busy`、状态栏提示、AI 遮罩 |

- `dshgen.js` 的 `setRunning()` 里登记/注销；
- `ai.js` 的 `prepare()` 先查 `blocker('ai')`，有就 toast 并返回 null；面板上加一层 `.ai-busy-overlay`；
- 正文不受影响（editor 不参与忙状态），所以"AI 生成中手改"始终可用；
- MCP 写入走 `beforeExternalWrite()` → `afterExternalWrite()`：先 `Editor.flushSnapshot()` 把正在敲的内容写回模型并 `saveCaret()`，写完 `restoreCaret()`。

### 8.5 子进程生命周期（防孤儿进程）

`dsh headless` 与 `mcp-server.js` 都是外部 node 进程，宿主被杀时必须能一起收走：

| 环节 | 实现 |
| --- | --- |
| 登记 | `electron/dsh.js` 的 `trackChild()` 把子进程放进 `live` 集合，`setChildWatcher()` 把 PID 列表交给主进程，400ms 防抖写 `USER_DIR/children.json` |
| 正常退出 | `before-quit`：`dshJob.abort()` → `dsh.killAllLive()` → 删 `children.json` |
| 崩溃后重启 | `cleanupStaleChildren()` 读 `children.json` → `Get-CimInstance Win32_Process` 核对命令行（只认 node.exe/cmd.exe 且匹配 headless/--json/mcp-server/ai-script/dsh）→ `taskkill /PID /T /F` → 写 `[cleanup]` 日志 |
| MCP server | stdin end/close/error → `shutdown(0)`；SIGTERM/SIGINT/SIGHUP/disconnect → `shutdown(0)`；未捕获异常 → stderr + `shutdown(1)` |
| 日志 | `USER_DIR/logs/app.log`（1MB 轮转 `app.log.1`），标签 `[boot]` `[gateway]` `[cleanup]`；关于面板有「打开日志目录」按钮（IPC `app:openLogs`） |

### ⚠️ 必看：Electron 二进制没装上的坑

**npm 11 默认拦截 package 的 install script**，所以 `npm install` 之后 `node_modules\electron\dist\electron.exe` 可能根本不存在，`npm start` 会报 `Electron failed to install correctly`。手动补一次：

```powershell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
node node_modules/electron/install.js
```

看到 `ELECTRON_BINARY_OK` 就成功了。

## 11. 自测体系

205 条断言，分两边执行：

| 文件 | 角色 |
| --- | --- |
| `electron/smoke.js` | 驱动：打桩文件对话框、拉起 mock AI、注入假 dsh 命令、跑完收尾、跑 MCP 断言 |
| `electron/smoke-renderer.js` | 场景：在页面里逐步操作并断言（新建/编辑/撤销/小节/标签/查找/保存/导入/导出/设置/主题/壁纸/浮窗/AI/DSH/网关） |
| `electron/mock-ai.js` | 本地 SSE 假 AI（端口随机），验证流式、采纳、错误提示 |
| `scripts/fake-dsh.js` | 假 dsh headless --json，按 NDJSON 吐一段固定 JSON 剧本 |

几条设计约束，改测试时别破坏：

1. **不碰真实设置**：--smoke / --shot 都换到临时 userData；
2. **不碰真实 DSH**：假 dsh 的路径通过 window.__SMOKE_DSH 注入；打包后 fake-dsh.js 在 asar 里普通 node 读不到，所以 smoke.js 会先把它复制到临时目录；
3. **MCP 断言从主进程发**：页面 CSP 的 connect-src 只允许 self，挡住了渲染进程直连本地桥，所以 HTTP 断言写在 smoke.js 里；
4. **打包产物也要跑**：dist\win-unpacked\AI Script Studio.exe --smoke 能发现「开发能跑、打包坏掉」这类问题（历史上就抓到过 fake-dsh 读不到）。

```powershell
# 开发模式
$env:SMOKE_OUT = "smoke-out.txt"
npx electron . --smoke

# 打包产物
$env:SMOKE_OUT = "smoke-pkg.txt"
Start-Process -FilePath "dist\win-unpacked\AI Script Studio.exe" -ArgumentList "--smoke" -Wait

```powershell
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"

| 产物 | 说明 |
| --- | --- |
| dist/AI Script Studio-<版本>-x64.exe | NSIS 安装版（可选目录、桌面/开始菜单快捷方式） |
| dist/AI Script Studio-<版本>-portable.exe | 免安装版（每次启动解压 3~8 秒） |

`package.json` 里几个关键项：

- `build.files`：打进 asar 的白名单。**新增目录必须加进来**，否则开发能跑、安装版说找不到文件；
- `build.win.target`：nsis + portable，都 x64；
- `build.asar: true`；
- `build.artifactName`：产物命名模板；
- `prebuild`：`node scripts/make-icon.js` —— 图标是二进制，仓库里不提交，每次打包前重新生成 build/icon.png。

> 图标为什么不用图片提交？因为 GitHub 的文本接口传不了二进制。生成脚本 `scripts/make-icon.js` 是纯 Node（zlib 手写 PNG），3 倍超采样画紫色渐变圆角方块 + 三条白条 + 星芒，512×512。

## 13. 加一个新功能

三步，缺一不可（安全模型要求走主进程）：

**① 主进程注册 handler**（electron/main.js）

```js
ipcMain.handle('demo:hello', async (event, name) => {
  return { ok: true, message: '你好，' + String(name || '世界') };
});
```

**② preload 暴露**（electron/preload.js）

```js
demoHello: (name) => ipcRenderer.invoke("demo:hello", name),
```

**③ 页面调用**

```js
const r = await window.api.demoHello('剧本');
console.log(r.message);
```

只改界面（不碰文件/网络/剪贴板）的话，直接在 src/js/* 里写就行 —— 12 个脚本是全局变量风格，window.App / Project / Editor 互相能拿到。

## 14. 踩坑记录

这些是实际调试过的坑，别重复走：

| 坑 | 现象 | 原因 / 修法 |
| --- | --- | --- |
| 本地 SSE 服务永不返回 | 客户端 8 秒超时，服务端日志显示已启动 | 用 req.on(close) 清定时器，而 IncomingMessage 的 close 在**请求体读完时**就触发了 → 改成 res.on(close) |
| 模块顶层读 settings 崩 | 启动弹「App threw an error during load」，窗口不出现 | 顶层 let settings = null 在 loadSettings() 之前，顶层直接读 settings.mcp.port 会炸 → 顶层不要碰 settings |
| --shot 污染真实配置 | 拍完截图，真实设置里的 API Key 被改成 mock 地址 | 现在 --shot / --smoke 都换临时 userData；仍要小心任何直接写 USER_DIR 的脚本 |
| asar 里的假 dsh 跑不起来 | 打包版冒烟失败，开发版正常 | asar 内文件普通 node 读不到 → smoke.js 先复制到临时目录 |
| [hidden] 不生效 | 本该隐藏的面板显示出来 | 自定义 display:flex 压过 UA 的 [hidden] → 全局加 [hidden]{display:none !important} |
| 长文本溢出纸张 | 正文跑到纸外面、滚动条怪 | .editor-scroll 用了 display:flex，子项被拉满高度 → 改回普通块级 + .paper{margin:0 auto} |
| 全局 .opt-row 污染 AI 面板 | 「模型 / 上下文」被挤成纵向居中 | 新样式只写 #dshModal .opt-row，加作用域 |
| PowerShell 调 GUI 不等待 | 打包版测试没跑完就继续 | & 不等待 → 用 Start-Process -Wait，且**路径含空格要自己拼引号**（把整个参数字符串拼好再传 -ArgumentList） |
| 写长文档语法报错 | Expected a semicolon | 一个巨大的 template literal 里转义反引号/反斜杠容易踩到解析 → 改成「字符串数组 + join」 |
| 缓存告警噪音 | stderr 一堆 Unable to create cache | Chromium 磁盘缓存告警，多实例同时跑时出现，**无害** |
| 冒烟被上次运行污染 | 第二次跑断言失败（默认 3 章变成 1 章） | 真实 userData 里残留 autosave.json → 测试固定用临时 userData |
| 子进程登记文件读不出 PID | 清理逻辑不生效，假进程还活着 | PowerShell 5.1 的 `Set-Content -Encoding UTF8` 会写 **BOM**，`JSON.parse` 直接抛错 → 读文件先 `.replace(/^\uFEFF/, '')` |
| MCP server 变孤儿进程 | 关掉宿主后任务管理器里还留着 node | stdin 结束时没有退出 → 监听 `stdin` 的 end/close/error 并 shutdown(0)；另加 SIGTERM/SIGINT/SIGHUP/disconnect |
| 未捕获 rejection 杀进程 | MCP server 偶发直接消失 | Node 15+ 默认把未处理的 rejection 当致命错误 → 注册 `unhandledRejection`/`uncaughtException` 后写 stderr 再优雅退出 |
| dev 模式 Start-Process 调 electron.exe 失败 | exit=1，没有日志也没有截图 | 参数里必须先给应用目录：`node node_modules\electron\cli.js . --shot x.png`（或 `electron.exe . --shot x.png`） |

## 16. 代码风格

- 2 空格缩进，单引号，语句带分号；
- 渲染层每个文件一个 IIFE，导出一个 window.Xxx 对象；
- 注释用中文，写「为什么」不写「做了什么」；
- 不引入新依赖除非确实必要（当前只有一个 docx）；
- 面向用户的文案一律中文，报错要给「怎么办」而不只是「哪里错」。
